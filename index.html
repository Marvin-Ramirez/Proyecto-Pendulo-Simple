Modelo físico

El periodo se obtiene cronometrando el tiempo t que tardan n oscilaciones completas:

T = t / n

Luego, para calcular la gravedad a partir del periodo medido se usa:

g = 4π²L / T²

Supuestos: hilo inextensible, rozamiento del aire y del soporte despreciables. La masa no afecta el periodo. El modelo trabaja bajo la aproximación de un ángulo pequeño (≤20°).
